# Apple Notes 复刻：重新规划

目标：以 **macOS Sonoma / Sequoia 版「备忘录」(Notes.app)** 为基准，在浏览器中复刻其界面与交互；窄屏（< 768px）时切换为 **iOS 版「备忘录」** 的逐级导航布局。

## 0. 现状评估

| 问题        | 说明                                                                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 重复/死代码 | `MainLayout` / `EnhancedMainLayout` / `layout/*` 三套布局、`NoteEditor` / `BasicNoteEditor` 两套编辑器、`lib/design-system`、`lib/components/ui` 等大量未用代码 |
| 外观偏离    | 卡片式列表、蓝色按钮、Tailwind 默认灰阶，与 Apple 备忘录差异明显                                                                                                   |
| 编辑器      | 纯 `textarea`，无富文本；标题与正文分离，不符合「首行即标题」                                                                                                      |
| 无持久化    | 刷新即丢失全部数据                                                                                                                                                 |
| 缺失功能    | 最近删除、日期分组、画廊视图、右键菜单、快捷键、核对清单、标签解析等                                                                                               |

结论：保留技术栈（Next.js 14 + Redux Toolkit + Tailwind + lucide-react），**重写 UI 层与数据层**，删除全部死代码。

## 1. 数据模型

```ts
Note {
  id: string
  folderId: string          // 内置「备忘录」文件夹 id = 'notes'
  html: string              // 富文本正文（首行即标题）
  title: string             // 由 html 派生：首行文本
  snippet: string           // 由 html 派生：第二行起的纯文本摘要
  tags: string[]            // 由正文中的 #标签 派生
  isPinned: boolean
  createdAt: string
  updatedAt: string
  deletedAt: string | null  // 非 null 即位于「最近删除」
}

Folder { id, name, parentId: string | null, createdAt }
```

- `title` / `snippet` / `tags` 在每次编辑时由 `lib/note.ts` 统一派生，列表渲染无需解析 HTML。
- 删除 = 设置 `deletedAt`（进入「最近删除」，保留 30 天，启动时清理过期项）；在「最近删除」中删除 = 永久删除；「恢复」= 清空 `deletedAt` 回原文件夹（原文件夹不存在则回「备忘录」）。
- 删除文件夹 → 其中备忘录移入「最近删除」，子文件夹一并删除。

## 2. 状态管理（Redux Toolkit）

| Slice     | 状态                                                                                                                                                                                                              | 主要 action                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `notes`   | `notes[]`                                                                                                                                                                                                         | `createNote` `editNote` `trashNote` `restoreNote` `destroyNote` `togglePin` `moveNote` `duplicateNote` `purgeExpired` |
| `folders` | `folders[]`                                                                                                                                                                                                       | `createFolder` `renameFolder` `removeFolder`                                                                          |
| `ui`      | `selection`（文件夹 / 标签 / 最近删除）、`selectedNoteId`、`search`、`viewMode`(list/gallery)、`sortBy`、`groupByDate`、`sidebarVisible`、`sidebarWidth`、`listWidth`、`focus`(sidebar/list/editor)、`mobilePane` | 对应 setter                                                                                                           |

- 选择器集中在 `store/selectors.ts`（`createSelector` 记忆化）：可见备忘录、日期分组、文件夹计数、标签集合。
- 持久化：`store/persistence.ts` 订阅 store，节流 300ms 写入 `localStorage`；捕获配额超限。应用以 `ssr: false` 动态加载，启动时同步读取，避免水合不一致。

## 3. 界面（macOS 三栏）

### 3.1 侧边栏

- 半透明浅灰背景；顶部工具栏仅「显示/隐藏边栏」按钮。
- 分组标题「iCloud」：内置「备忘录」、用户文件夹（支持子文件夹折叠三角）、「最近删除」（有内容时才显示）。每项：黄色文件夹图标 + 名称 + 右侧灰色计数。
- 选中项：圆角浅灰底；焦点在侧边栏时为强调色底。
- 分组标题「标签」：「所有标签」+ `#标签` 胶囊，点击按标签筛选。
- 底部「⊕ 新建文件夹」。双击/右键重命名，右键菜单：新建文件夹、重新命名、删除文件夹。
- 拖放备忘录到文件夹即可移动。

### 3.2 备忘录列表

- 顶部工具栏：列表/画廊切换（分段控件）、删除按钮；标题区显示文件夹名与「N 个备忘录」。
- 按日期分组：置顶、今天、昨天、过去 7 天、过去 30 天、本年各月（「9月」）、往年（「2025」）。可在排序菜单关闭分组。
- 行样式：粗体标题；第二行「时间 + 灰色摘要」；搜索/标签视图下第三行显示所在文件夹；行间细分隔线。
- 选中：列表获得焦点时黄色底，否则浅灰底。
- 画廊视图：缩略卡片（正文缩略预览）+ 标题 + 日期。
- 右键菜单：置顶/取消置顶、移到 ›（文件夹列表）、复制备忘录、删除；「最近删除」中：恢复、永久删除。
- 「最近删除」顶部提示：「备忘录在删除后会保留 30 天。之后，它们将被永久删除。」
- 键盘：↑/↓ 切换选中，⌫ 删除。

### 3.3 编辑器

- 顶部工具栏：新建备忘录（✎）、`Aa` 格式菜单、核对清单、表格、附件（插入图片）、右侧搜索框。
- 正文顶部居中灰色显示编辑时间「2026年10月6日 14:32」。
- `contentEditable` 富文本，新备忘录首行默认「标题」样式。
- `Aa` 菜单：**B** _I_ U S 行内样式；标题 / 小标题 / 副标题 / 正文 / 等宽字体；项目符号列表 / 短划线列表 / 编号列表；块引用。
- 核对清单：圆形勾选框，勾选后黄色实心圆 + 白色对勾，点击圆圈切换。
- 表格：插入 3×2 可编辑表格。
- 图片：本地选择后缩放压缩为 JPEG 再内联。
- 粘贴：清理外部格式，仅保留纯文本（避免外来样式与脚本）。
- 「最近删除」中的备忘录只读，提示「恢复后才能编辑」。

### 3.4 搜索

- 工具栏搜索框（⌘F 聚焦），在当前账户所有未删除备忘录中搜索标题与正文；结果列表显示所在文件夹并高亮匹配词；Esc 清空。

### 3.5 快捷键（与 macOS 一致）

| 快捷键                | 功能                          |
| --------------------- | ----------------------------- |
| ⌘N                    | 新建备忘录                    |
| ⇧⌘N                   | 新建文件夹                    |
| ⌘F                    | 搜索                          |
| ⌥⌘S                   | 显示/隐藏边栏                 |
| ⌘1 / ⌘2               | 列表 / 画廊视图               |
| ⇧⌘T / ⇧⌘H / ⇧⌘J / ⇧⌘B | 标题 / 小标题 / 副标题 / 正文 |
| ⇧⌘M                   | 等宽字体                      |
| ⇧⌘L                   | 核对清单                      |
| ⇧⌘U                   | 勾选/取消勾选                 |

（Windows/Linux 下 ⌘ 对应 Ctrl。）

### 3.6 外观

- 字体 `-apple-system, "SF Pro Text", "PingFang SC", system-ui`，移除 Google Inter。
- 颜色以 CSS 变量定义，跟随系统深色模式（`prefers-color-scheme`），与 macOS 一致不提供手动开关。
- 边栏与列表宽度可拖动分隔线调整并记忆。

### 3.7 窄屏（iOS 风格）

- 三级页面：文件夹 → 备忘录列表 → 编辑器；大标题、`‹ 文件夹` / `‹ 备忘录` 返回按钮。
- 底部工具栏：「N 个备忘录」+ 新建按钮。

## 4. 不在范围内（需要 Apple 账户/系统能力）

锁定备忘录、协作共享、iCloud 同步、扫描文稿、手绘、智能文件夹、链接预览、语音转写。界面中不放置无法使用的按钮。
